# Fuidzy — desktop downloads

Installers for **Fuidzy**, your day on one timeline. Free; no account needed to start.

**Get it at [fuidzy.com/download](https://fuidzy.com/download)** — it picks the right file for your computer.
Or use it in the browser at [app.fuidzy.com](https://app.fuidzy.com).

| System | File |
|---|---|
| Windows 10 / 11 | `Fuidzy-Setup.exe` |
| macOS 11+ | `Fuidzy.dmg` |
| Linux (Debian/Ubuntu) | `fuidzy-linux-x64.deb` |
| Linux (other) | `fuidzy-linux-x64.tar.gz` |

Every file is under [Releases](https://github.com/dznye/fuidzy-downloads/releases/latest).

**Windows:** if SmartScreen shows "unknown publisher", choose *More info → Run anyway*. Installs for your account only, no admin rights needed.
**Mac:** open the disk image, drag Fuidzy to Applications, then the first time right-click it and choose *Open*.
**Updating:** install the newer version over the old one. Your plans stay where they are.

This repository only holds the installers; it contains no source code.
